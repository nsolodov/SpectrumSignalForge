## О проекте

**SpectrumSignalForge** — это профессиональный программный комплекс для моделирования, анализа и исследования цифровых систем связи, радиосигналов и алгоритмов цифровой обработки сигналов. Приложение представляет собой полноценный инженерный инструмент, объединяющий более десяти специализированных модулей в единой среде.

Данный проект является моей первой полноценной программной разработкой, реализованной с нуля и собранной в готовый установочный пакет для операционной системы Windows. В ходе работы над проектом я освоил полный цикл разработки программного обеспечения: от проектирования архитектуры и написания кода до сборки исполняемого файла и создания профессионального установщика.

### Цель создания

Проект разрабатывался как демонстрационный продукт, призванный продемонстрировать мои компетенции в следующих областях:

- Проектирование модульной архитектуры программного обеспечения
- Реализация алгоритмов цифровой обработки сигналов
- Разработка графических интерфейсов на базе Qt
- Работа с научными библиотеками NumPy и SciPy
- Сборка и упаковка приложений для распространения

### Принципы разработки

При создании приложения я руководствовался следующими принципами:

1. **Модульность**: Каждый компонент системы выполняет строго одну задачу и не зависит от других модулей. Это позволяет легко добавлять новые функции и модифицировать существующие.

2. **Разделение ответственности**: Весь код разделен на три основных слоя — вычислительное ядро (core), пользовательский интерфейс (ui) и сервисный слой (services). Такое разделение обеспечивает независимость логики от интерфейса.

3. **Масштабируемость**: Архитектура спроектирована таким образом, что добавление нового алгоритма или модуля не требует изменения существующего кода.

4. **Профессиональный интерфейс**: Внешний вид приложения максимально приближен к профессиональным инженерным продуктам, таким как MATLAB, GNU Radio Companion и LabVIEW.

## Функциональные модули

Приложение построено по модульному принципу и включает следующие инструменты:

### 1. Генератор сигналов

Модуль предназначен для создания различных типов сигналов с настраиваемыми параметрами. Пользователь может выбрать тип сигнала, задать амплитуду, частоту, фазу, длительность и частоту дискретизации. Сигнал отображается на графике в реальном времени.

**Поддерживаемые типы сигналов:**

- Синусоидальный
- Прямоугольный (меандр)
- Треугольный
- Пилообразный
- Белый шум
- Линейный частотно-модулированный (chirp)
- Импульсный
- Ступенчатый

**Принцип работы:** При изменении любого параметра сигнал автоматически перегенерируется с использованием математических функций NumPy и отображается на графике с помощью PyQtGraph.

**Настраиваемые параметры:**

- Амплитуда (0.01 ... 10.0)
- Частота (0.1 ... 100000 Гц)
- Фаза (0 ... 360 градусов)
- Длительность (0.001 ... 10 секунд)
- Частота дискретизации (1000 ... 1000000 Гц)
- Скважность (для прямоугольного сигнала)
- Начальная и конечная частота (для chirp-сигнала)

**Дополнительные функции:**

- Добавление аддитивного белого гауссовского шума с регулируемым SNR
- Автоматическая перегенерация при изменении параметров

---

### 2. Анализатор спектра

Модуль выполняет частотный анализ сигнала с использованием быстрого преобразования Фурье (FFT). Пользователь может настраивать размер БПФ, выбирать оконную функцию и переключать масштаб отображения.

**Доступные оконные функции:**

- Прямоугольное окно
- Окно Ханна
- Окно Хэмминга
- Окно Блэкмана
- Окно Блэкмана-Харриса
- Окно Кайзера
- Гауссово окно

**Режимы отображения:**

- Линейный масштаб
- Логарифмический масштаб (дБ)
- Спектральная плотность мощности (PSD)

**Принцип работы:** Сигнал умножается на выбранную оконную функцию, после чего вычисляется БПФ заданного размера. Результат отображается в виде графика зависимости амплитуды от частоты.

---

### 3. Проектировщик фильтров

Модуль позволяет проектировать цифровые фильтры различных типов и анализировать их частотные характеристики.

**Поддерживаемые типы фильтров:**

- Нижних частот (Lowpass)
- Верхних частот (Highpass)
- Полосовой (Bandpass)
- Заграждающий (Bandstop)
- Скользящее среднее (Moving Average)
- Медианный (Median)

**Методы проектирования:**

- Баттерворта
- Чебышёва I рода
- Чебышёва II рода
- Эллиптический
- Бесселя
- FIR на основе оконного метода
- FIR равнопульсовый (Parks-McClellan)

**Анализ фильтра:**

- Амплитудно-частотная характеристика (АЧХ)
- Фазо-частотная характеристика (ФЧХ)
- Групповая задержка
- Полюсно-нулевая диаграмма
- Оценка устойчивости

**Принцип работы:** На основе заданных параметров (тип фильтра, метод проектирования, порядок, частота среза) вычисляются коэффициенты фильтра, после чего строится его частотная характеристика.

---

### 4. Модуляция

Модуль предназначен для генерации модулированных сигналов с использованием различных схем цифровой модуляции.

**Поддерживаемые виды модуляции:**

- BPSK (Binary Phase Shift Keying)
- QPSK (Quadrature Phase Shift Keying)
- 8PSK (8-позиционная фазовая модуляция)
- 16QAM (16-позиционная квадратурно-амплитудная модуляция)
- 64QAM (64-позиционная квадратурно-амплитудная модуляция)
- OFDM (Orthogonal Frequency Division Multiplexing)
- FSK (Frequency Shift Keying)
- ASK (Amplitude Shift Keying)

**Принцип работы:**

1. Генерируется случайная битовая последовательность
2. Биты группируются в символы согласно выбранной схеме модуляции
3. Символы отображаются на сигнальные точки в комплексной плоскости
4. Выполняется импульсная формировка с использованием приподнятого косинуса
5. Сигнал переносится на несущую частоту

**Настраиваемые параметры:**

- Количество символов
- Частота дискретизации
- Символьная скорость
- Несущая частота
- Коэффициент сглаживания (roll-off)

---

### 5. Модели каналов связи

Модуль симулирует прохождение сигнала через различные каналы связи с добавлением искажений и шума.

**Доступные модели каналов:**

| Модель | Описание | Параметры |
|--------|----------|-----------|
| AWGN | Аддитивный белый гауссовский шум | SNR |
| Rayleigh | Релеевское замирание | SNR |
| Rician | Райсовское замирание | SNR, K-фактор |
| Free Space | Свободное пространство | SNR, потери на трассе |
| Urban | Городская среда | SNR, число лучей, задержка |
| Forest | Лесная среда | SNR, число лучей, задержка |
| Multipath | Многолучевое распространение | SNR, число лучей, задержка |

**Принцип работы:** Сигнал умножается на комплексный коэффициент канала, после чего добавляется шум с заданным SNR. Для многолучевых моделей сигнал суммируется с задержанными и ослабленными копиями.

**Дополнительные функции:**

- Отображение импульсной характеристики канала
- Отображение частотной характеристики канала
- Оценка доплеровского сдвига

---

### 6. Диаграмма созвездия

Модуль визуализирует сигнальные точки в комплексной плоскости, позволяя оценить качество модуляции и влияние шума.

**Отображаемая информация:**

- Сигнальные точки на комплексной плоскости
- Идеальные позиции созвездия
- EVM (Error Vector Magnitude) — показатель качества модуляции
- Статистика по квадратам
- Смещение по I и Q

**Поддерживаемые форматы созвездий:**

- BPSK
- QPSK
- 8PSK
- 16QAM
- 64QAM

**Принцип работы:** Принятый сигнал демодулируется и отображается на комплексной плоскости. EVM рассчитывается как отношение среднеквадратичной ошибки к амплитуде опорного сигнала.

---

### 7. Анализатор BER

Модуль рассчитывает вероятность битовой ошибки (BER) и символьной ошибки (SER) в зависимости от отношения сигнал/шум.

**Функциональность:**

- Расчет BER для различных типов модуляции
- Построение графика BER(SNR)
- Сравнение с теоретическими кривыми
- Расчет кодового усиления

**Выходные данные:**

- График BER в зависимости от SNR
- Значения BER и SER для каждого SNR
- Статистика ошибок

**Принцип работы:** Для каждого значения SNR генерируется последовательность битов, которая модулируется, проходит через канал с шумом, демодулируется и сравнивается с исходной последовательностью.

---

### 8. Спектрограмма

Модуль отображает эволюцию спектра сигнала во времени (водопадный график).

**Параметры:**

- Размер сегмента БПФ
- Перекрытие сегментов
- Тип оконной функции
- Цветовая карта

**Принцип работы:** Сигнал разбивается на перекрывающиеся сегменты, для каждого из которых вычисляется спектр. Результаты объединяются в двумерный массив, где по одной оси отложено время, по другой — частота, а цветом отображается амплитуда.

---

### 9. Радиолокация

Модуль моделирует работу радиолокационной станции.

**Функциональность:**

- Генерация зондирующих импульсов
- Моделирование отраженного сигнала от цели
- Расчет дальности до цели
- Расчет скорости цели по доплеровскому сдвигу
- Отображение переданного и принятого сигналов

**Параметры:**

- Длительность импульса
- Период повторения импульсов (PRI)
- Количество импульсов
- Дальность до цели
- Скорость цели
- SNR

**Принцип работы:**

1. Генерируется последовательность импульсов
2. Сигнал задерживается на время, соответствующее дальности
3. Добавляется доплеровский сдвиг для движущейся цели
4. Добавляется шум
5. Выполняется оценка дальности и скорости

---

### 10. Помехоустойчивое кодирование

Модуль демонстрирует работу алгоритмов помехоустойчивого кодирования, позволяя оценить их эффективность при передаче данных по зашумленному каналу.

**Реализованные коды:**

| Код | Тип | Описание |
|-----|-----|----------|
| Parity | Блочный | Простая проверка на четность |
| CRC | Блочный | Циклический избыточный код |
| Hamming | Блочный | Код Хэмминга (7,4) |
| Reed-Solomon | Блочный | Код Рида-Соломона (упрощенный) |
| Convolutional | Сверточный | Сверточный код (1/2, K=3) |

**Функциональность:**

- Кодирование и декодирование данных
- Внесение ошибок в закодированную последовательность
- Сравнение эффективности различных кодов
- Визуализация результатов сравнения

**Принцип работы:**

1. Генерируется случайная последовательность бит
2. Данные кодируются выбранным кодом
3. В закодированную последовательность вносятся ошибки
4. Выполняется декодирование с исправлением ошибок
5. Сравниваются исходные и декодированные данные

## Архитектура приложения

Приложение построено на модульной архитектуре с четким разделением ответственности между компонентами.

### Принципы архитектуры

1. **Разделение логики и интерфейса**: Все вычислительные алгоритмы изолированы в модулях core и не зависят от GUI. Это позволяет тестировать алгоритмы независимо от интерфейса и при необходимости использовать их в других проектах.

2. **Масштабируемость**: Добавление нового алгоритма или модуля не требует изменения существующего кода. Достаточно создать новый класс в core и соответствующий UI-класс в ui.

3. **Единая ответственность**: Каждый класс выполняет строго одну задачу. Например, SignalProcessor отвечает только за генерацию и обработку сигналов, а его интерфейс реализован в SignalGeneratorUI.

4. **Интерфейс через сервисы**: Взаимодействие между модулями осуществляется через сервисный слой, что обеспечивает слабую связанность компонентов.

5. **Конфигурируемость**: Настройки приложения хранятся в JSON-файле и загружаются через ConfigService, что позволяет изменять параметры без перекомпиляции.
